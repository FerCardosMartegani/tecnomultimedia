# tecnomultimedia

Este repositorio guarda los trabajos que hice para la materia Tecnología Multimedia 1 (según el plan de estudios 2006), sumando algunos ejemplos que hice como ayudante ad honorem.
En la cursada, usamos el lenguaje y entorno de [Processing](https://processing.org/), y posteriormente [p5.js](https://p5js.org/), para aprender nociones básicas de programación.
Cada programa está guardado como su propia branch, por pedido de la materia.


### Trabajos:
- tp0: Crear un dibujo simple usando sólo figuras primitivas de Processing.
- tp1: Recrear una secuencia de créditos en Processing, usando primitivas, imágenes, variables y condicionales.
- tp2: Recrear una ilusión óptica interactiva en Processing, usando primitivas, variables, funciones propias y ciclo for().
- tp3: Crear un minijuego en Processing, usando imágenes y funciones propias.
- tp4: Crear un escenario animado en Processing, usando Clases y Objetos.
- tp5: Crear un minijuego en Processing, usando Clases y Objetos.
- Web: Crear una página web con los frameworks dados.

### Desafíos:
Ejercicios sin nota propuestos por el profesor de la comisión.
- d01: Dibujar una diana con figuras primitivas y texto.
- d02: Hacer una pequeña animación automática con funciones matemáticas simples.
- d03: Programar un juego de ta-te-ti.
- desafioPOO: Armar una posible estructura de Clases y Objetos para dibujar una escena animada.
